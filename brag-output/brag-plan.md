# Brag Plan: Ornith-Flight

## What is this app?
Ornith-flight streams 35B parameter MoE model experts from disk to consumer hardware, making a 70GB+ model run on 8-16GB machines like MacBook Airs and gaming PCs.

## The angle
This is not fake. This is a real inference engine that runs a massive AI model on hardware it has no business running on. The video treats it like a genuine product launch because it IS one — the hook is the absurd gap between "35B parameters" and "8GB laptop," and the video lands on real benchmarks that prove it works. Tech hype, but earned.

## Hook (first 2-3 seconds)
"35 BILLION PARAMETERS." Big, bold, centered. Pause. Then "ON 8GB OF RAM." slams in beneath. The cognitive dissonance is the hook.

## Key moments (the middle)
1. The capacity gap: 70GB+ required vs 5.6GB used. Numbers flip/wipe.
2. The 4-tier memory pyramid: T0 resident -> T1 hot-store -> T2 LRU cache -> T3 disk stream. The core innovation visualized.
3. Real benchmarks: M2 MacBook Air and gaming PC speeds. The "Before: Cannot Run / After: Runs Comfortably" comparison.

## Outro / punchline
"ORNITH-FLIGHT" centered. Tagline: "Large models. Any hardware."

## User flow worth showing
None — CLI tool, no UI screens. Rely on product concept animation and benchmark visuals.

## Tone
- Preset: app-store
- Creative direction: hype tech product launch
- Interpretation: Feature-card clean with genuine excitement. Fast reveals. Big numbers. Real benchmarks as the proof. Energetic but not chaotic — the product earns the hype.
